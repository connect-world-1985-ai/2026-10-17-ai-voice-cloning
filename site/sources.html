Sources and method

How the research was done, which sources the key claims rest on, where sources disagree, and what is still missing.

Method

  1. Fresh research on 2026-10-17. Five research helpers gathered fact sheets on cloud services, open-source models, voice conversion and recording, evaluation and pipelines, and law. The main agent read every fact sheet, re-checked the most important claims against primary sources, made all judgements and wrote every page.
  2. Primary sources first: vendor documentation, pricing pages and terms; licence files; law texts and regulator guidance; arXiv papers (29 paper IDs checked against the arXiv API); GitHub repository data via the GitHub API (stars, licence, last push, archived flag). Secondary sources (blogs, news, search summaries) are labelled as such.
  3. Hugging Face was unreachable from the research machine; model-card licence tags were read via a public mirror of the Hugging Face API (hf-mirror.com), which returns the same JSON.
  4. No invented numbers. Where a value was not found it says "not stated" or "unverified". Per-hour prices are calculated from per-character list prices with stated assumptions.
  5. Benchmarks are usually self-reported by model authors; they are marked "as published".

Known gaps

  • No hands-on testing. No model was installed or run; quality statements come from benchmarks, arenas and documentation. Windows support for CosyVoice 3, Fish, Chatterbox and others is unverified in practice.
  • No independent own-voice benchmark exists for English plus Mandarin or for cross-lingual similarity; the CV3 cross-lingual table is compiled by one model team.
  • VRAM and speed figures are official only for a few models; others are secondary or missing.
  • Sample-audio licences on demo pages are not stated, so no audio is embedded; demo pages are linked instead.
  • Vendor terms for Inworld, Alibaba, Volcengine and the OpenAI TTS supplement were not read; Fish and Cartesia terms may be stale versions.
  • Not researched in depth: HeyGen Voice (#1 on the cloned board), StepAudio, Voxtral TTS, Breeze TTS 2, Supertone, Maya1, Magpie TTS, LongCat-Audio-DiT.
  • Legal: no authority has yet ruled on someone cloning their own voice under Art. 50; German judgments were read only via secondary summaries.
