Three paths

  1. ElevenLabs Starter ($6/month): Instant Voice Clone from 1–2 minutes of clean audio per language. Turn off "Improve the models for everyone" on day 1.
  2. Generate a lesson in the web app with Eleven v4; add problem words to a pronunciation dictionary.
  3. For a cheap comparison, also try Gemini 3.8 Flash TTS voice replication on the paid tier (about $0.82 per audio hour).
  4. When it works, move to the API and the pipeline on page 8; upgrade to Creator ($22) for a Professional Voice Clone if Instant is not close enough.

Why: fastest to a good result, Mandarin and English, commercial on any paid plan, best API for automation. Verified (prices and features) · choice Inference

  1. Hardware: an NVIDIA card with 8 GB or more, or an hourly rental (RTX 3090 about $0.50/h on RunPod, 2026-10-17). Your current Intel-graphics PC can run only CPU paths, slowly.
  2. Start with GPT-SoVITS (MIT): the official Windows one-click package; zero-shot from 5 s, then fine-tune on a few minutes of your voice.
  3. Compare with VoxCPM2 (Apache-2.0, ~8 GB) for zero-shot similarity, and Fun-CosyVoice 3 (Apache-2.0) if you need pinyin overrides and instruction control.
  4. Build the pipeline around the winner; all three have Python APIs, VoxCPM2 and CosyVoice 3 also HTTP servers.

Why: commercially clean licences, Mandarin-strong, your voice stays local. Verified (licences) · choice Inference

  1. Record properly (page 6): 1–3 hours of clean audio in your main language, 30+ minutes in the other.
  2. ElevenLabs Creator ($22/month) Professional Voice Clone on Eleven v4, trained on that set.
  3. Test the runners-up for Mandarin specifically: MiniMax Speech 2.8 HD, Alibaba Qwen-Audio, Cartesia Sonic 3.6; independent Mandarin rankings are only secondary reports, so trust your own A/B test.
  4. Pipeline with dictionaries, request stitching, ASR checks and forced alignment (page 8); human listening on flagged chunks.

Why: highest independent listener ratings among services an individual can use, plus a clone trained on far more of your voice. Verified (arena, plan features) · choice Inference
