开源的声音克隆模型

开源模型在标准基准上已经追上或超过闭源模型，而且声音留在你自己的机器上。卡住你的不是音质，是许可证（很多强模型禁止商用）、硬件（大多数要 NVIDIA 显卡），以及 Windows 支不支持。

结论（2026-10-17 的状态）
  • 商用干净、英语、普通话和跨语言都能做（代码和权重都是 Apache-2.0 或 MIT）：VoxCPM2、Fun-CosyVoice 3（0.5B）、Qwen3-TTS、GPT-SoVITS、Chatterbox Multilingual。已核实（许可证原文和 Hugging Face 标签；主代理复核了 VoxCPM、CosyVoice 3、Qwen3-TTS）
  • 权重非商用，做实验可以，付费课不行：F5-TTS、XTTS-v2（许可明确覆盖输出）、Fish Audio S2-Pro / Drama 3、Spark-TTS、MaskGCT、Llasa。已核实（主代理重读了 F5、XTTS、Fish 的许可）
  • Windows 上最好上手：GPT-SoVITS，唯一有官方一键 Windows 包的，大约一分钟你的声音就能微调。已核实（README）
  • 你现在这台电脑（Intel UHD 核显，没有 NVIDIA）只能慢慢跑其中少数几个。计划一块 8–24 GB 的 NVIDIA，或按小时租 GPU；见下面的硬件。推断

建议的短名单

VoxCPM2（OpenBMB）

Apache-2.0。20 亿参数，30 种语言，48 kHz，大约 8 GB 显存。可商用模型里自报相似度最高（SIM 英语 75.3 / 中文 79.5）。跨语言不用语言标签；支持 LoRA 微调；可通过 vLLM-Omni 开一个兼容 OpenAI 的服务。演示页

Fun-CosyVoice 3 0.5B（阿里）

Apache-2.0。有明确的跨语言模式，能用指令控制语速和情绪，技术词可以用拼音和音素修正，18 种以上汉语方言，有 FastAPI / gRPC 服务。安装以 Linux 为主：Windows 上预期用 WSL2。演示页

Qwen3-TTS 1.7B（阿里 Qwen）

Apache-2.0。3 秒加文稿就能克隆；自报错误率很低；大约 5–6 GB 显存（二手）。仓库自 2026-03-17 起很安静。长旁白用 1.7B，不要用 0.6B（二手报道）。

GPT-SoVITS

MIT。官方 Windows 一键包，自带切片、语音识别和标注，用大约一分钟或更多你的录音来微调。中文血统很强。零样本还不够「像你」时走这条。

也值得看：IndexTTS-2.5（哔哩哔哩）自报的跨语言相似度最好，时长和情绪控制细；许可在月活一亿或年收入十亿人民币以下免版税，但 README 写商用要联系哔哩哔哩，付费产品上线前先问。Chatterbox（MIT）安装最简单，但每段输出都带听不见的水印，参考语言和目标语言不同时口音会漏过去。已核实

怎么读这些基准
  • 错误率已经分不开第一档：朗读句子上，几乎都在人类水平或更低。相似度和你自己的耳朵更要紧。推断
  • 跨语言相似度大约掉 10 个点（中→英 SIM 56–68，同语言是 71–80）。「另一门语言」的声音会没那么像你。没有找到英→中的数字。已核实（CV3 表）· 解释推断
  • 有听者投票的竞技场只测英语，而且大多用库存声音。独立克隆音色榜上，列出的最好开源模型远低于顶尖云服务（Chatterbox 930，XTTS-v2 830，Eleven v4 是 1159）。上面短名单里的大多数根本不在那张榜上。已核实

许可证陷阱

  • 代码许可 ≠ 权重许可。F5-TTS：「代码按 MIT 发布。预训练模型因训练数据 Emilia 采用 CC-BY-NC。」Spark-TTS、MaskGCT 等是同一模式。已核实（主代理重读 README）
  • XTTS-v2 明确覆盖输出：「本许可只允许对机器学习模型及其输出做非商用。」Coqui 已经关闭，没有人可以卖商用许可。已核实（许可原文）
  • Fish Audio：代码许可不是权重许可。代码许可允许商用，「仅当你的年收入低于 50 万美元」；S2-Pro 权重许可写着「本协议不授予任何商用权利。」已核实（两份原文）
  • IndexTTS：免版税使用；月活超过一亿或年收入超过十亿人民币要另签许可；禁止用它或它的输出「改进任何人工智能模型，非商用模型除外」。README 另写「商用与合作请联系」。个人课程从正文看似乎允许；发邮件确认。已核实（许可原文）· 读法推断
  • OmniVoice：不清楚。研究助手说 README 里有非商用权重声明；主代理在 2026-10-17 的当前 README 里没找到；仓库是 Apache-2.0，Hugging Face 卡片没有许可标签，训练数据部分用了 Emilia（非商用）。澄清之前按非商用对待。未核实
  • Higgs TTS 3：研究与非商用，外加一份创作者授权：在你自己拥有的频道上变现视频和播客，并注明 “Boson AI's Higgs Audio”。课放在你不拥有的平台上，说不清。已核实（助手读过许可）
  • 非商用条款是否延伸到你生成的音频，法律上有争议。保守读法：只要可能商用，只用标了「可以」的模型。推断

已撤回、停滞和受限

  • VibeVoice TTS（微软）：「我们已从本仓库移除 VibeVoice-TTS 代码」（2025-09-05），原因是被滥用；README：「仅供研究与开发」。只剩社区分支。不要放进长期流水线。已核实（主代理重读 README）
  • Coqui TTS：原仓库自 2024-08 起无人维护；idiap 分支（coqui-tts，有 Windows 轮子）还在维护。已核实
  • MegaTTS3：Apache-2.0，但声音编码器没有发布；你得把样本上传到一个 Google 云端硬盘文件夹，才能拿到可用的声音潜变量。这就失去了「私有本地克隆」的意义。已核实（README）
  • 没有中文，或不能克隆：Kyutai Pocket TTS（CPU 优先，英语和欧洲语言）、Sesame CSM、Dia2、Orpheus（以英语为中心）、Kokoro（很好，但只有预设声音）。已核实
  • 停滞（12 个月以上没有推送）：Spark-TTS、Zonos、OpenVoice V2、StyleTTS 2、Sesame CSM。已核实（GitHub API）

硬件：什么能在哪里跑

配置现实情况
你今天的电脑：Intel UHD 核显，64 GB 内存只能 CPU。GPT-SoVITS 有 CPU 安装选项（自报在 Apple M4 上 RTF 0.53；x86 笔记本 CPU 多半更慢）。Chatterbox 能在 CPU 上跑。VoxCPM 有 GGUF 构建（M4 Pro 上 RTF 约 1.8，比实时慢）。MeanVC2 声音转换带一个纯 CPU 的 Windows 可执行文件。预期一分钟音频要算好几分钟。未核实（x86 上）
8 GB NVIDIA（例如 RTX 4060）VoxCPM2（约 8 GB，很紧）、Qwen3-TTS 1.7B、GPT-SoVITS、Chatterbox；IndexTTS2 在边缘。已核实（VoxCPM）· 其余未核实
12–16 GB短名单全部从容，外加 FireRedTTS-2（9 GB）。推断
24 GB（RTX 3090 / 4090）这里的全部，包括 40 亿参数模型（Fish S2-Pro、Higgs TTS 3）用来评测。推断
租来的 GPU2026-10-17，RunPod 列出 RTX 3090（24 GB）每小时 0.50 美元，L4（24 GB）0.59 美元，RTX 4090（24 GB）0.89 美元。实时因子 0.3 时，一小时旁白大约要 20 分钟 GPU 时间，再加准备和重录。已核实（价格）· 耗时推断

速度是高端显卡上的自报数字（VoxCPM2 在 RTX 4090 上 RTF 约 0.30；IndexTTS2.5 为 0.21；GPT-SoVITS v2ProPlus 为 0.014）。你的数字会不同。
