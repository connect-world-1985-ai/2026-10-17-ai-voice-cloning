来源与方法

研究是怎么做的，关键说法靠哪些来源，来源在哪里打架，还缺什么。中文页译自同一份研究，链接和数字没有改。

方法

  1. 2026-10-17 的新研究。五个研究助手分别整理了云服务、开源模型、声音转换与录音、评测与流水线、法律的事实表。主代理读了每一份，把最重要的说法重新对着一手来源核对，做了全部判断，写了每一页。
  2. 先一手来源：供应商文档、价格页和条款；许可证文件；法律文本和监管说明；arXiv 论文（29 个论文编号对着 arXiv API 核对过）；GitHub 仓库数据走 GitHub API（星标、许可证、最后推送、是否归档）。二手来源（博客、新闻、搜索摘要）会标出来。
  3. Hugging Face 从研究机器上连不上；模型卡上的许可证标签是通过 Hugging Face API 的公开镜像（hf-mirror.com）读的，返回的是同一份 JSON。
  4. 不编数字。找不到的值写成「未说明」或「未核实」。每小时价格是用标明的假设，从按字标价算出来的。
  5. 基准通常是模型作者自己报的，标成「按发表」。

来源在哪里打架

题目矛盾本站怎么处理
ElevenLabs 跨语言口音v4 发布稿说每种语言都是母语口音；更早的专业克隆指南警告源语言口音会带过去。两句都写了；你自己测（第 12 页，方向 4）。
ElevenLabs Creator 额度价格页：12.1 万积分；API 价格页：「含 27.5 万字 v4 语音合成」。计算器里不用这个数。
Fish Audio 免费档服务条款：非商用；价格页：「允许商用」。标成有条件。
Fish 权重许可README 暗示社区许可覆盖权重；S2-Pro 和 Drama 3 的许可文件写的是仅研究。信许可文件：非商用。
IndexTTS 商用许可正文：门槛以下免版税；README：「商用请联系」。标成有条件；上线前发邮件。
OmniVoice 权重助手报告 README 里有 CC-BY-NC；当前 README 没有；Hugging Face 卡片没有标签。标成不清楚。
Qwen3-TTS 基准它自己的 README 是 0.77 / 1.24；VoxCPM 的表是 1.22 / 1.23。用汇总表，并注明冲突。
Google Chirp 3 HD 的 SSML一页说预览里支持，另一页说不支持。标成未核实。
普通话克隆音色排名只有二手报道说 Artificial Analysis 有普通话榜（快照日期不明）。标成未核实；不拿来做推荐。
Resemble 的所有权条款首席执行官 2024 年证词：「用户拥有全部权利」；现行条款没有这一句（二手综述）。已无实际意义：托管产品停了。
YouTube 响度目标「−14 LUFS」被广泛引用；没找到 YouTube 官方页面。改推荐 −16 LUFS。
克隆自己的声音算不算深度伪造欧盟指南里的播客例子倾向于算；虚构旁白的例子说，如果没有欺骗就不算。做声明：两种读法都盖住了。

已知缺口

  • 没有动手跑模型。没有安装或运行任何模型；音质说法来自基准、竞技场和文档。CosyVoice 3、Fish、Chatterbox 等在 Windows 上好不好用，实践中未核实。
  • 没有独立的「你自己的声音」基准覆盖英语加普通话，或跨语言相似度；CV3 的跨语言表是一个模型团队编的。
  • 显存和速度只有少数模型有官方数字；其余是二手或缺失。
  • 演示页上的样音许可证没有写明，所以不内嵌音频，只给链接。
  • 供应商条款：Inworld、阿里、火山引擎和 OpenAI 语音合成补充条款没有读完；Fish 和 Cartesia 的条款可能是旧版本。
  • 没有深入查：HeyGen Voice（克隆榜第一）、StepAudio、Voxtral TTS、Breeze TTS 2、Supertone、Maya1、Magpie TTS、LongCat-Audio-DiT。
  • 法律：还没有任何机关裁定过，一个人按第 50 条克隆自己的声音算什么；德国判决只通过二手摘要读过。
