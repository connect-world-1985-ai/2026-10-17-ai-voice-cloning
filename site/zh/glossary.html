术语

本指南里用到的语音人工智能术语，每条一两句话。可以打字筛选。英文原名留在词条里，方便你对照论文和文档。

术语意思用在
盲听 A/B听者按随机顺序听两段，不知道哪段是哪个工具做的，再选更好的一段。比较「你自己喜不喜欢」最可靠的办法。7、11
声学模型语音合成系统里把文本（或文本符号）变成中间音频表示的部分，例如梅尔频谱或编解码符号。1
强制对齐已知音频和它的文稿，找出每个词或音素的起止时间。用来做字幕、对准幻灯片。8
ASR 语音识别自动语音识别（语音转文字），例如 Whisper、Paraformer、SenseVoice。这里用来检查合成语音是不是把稿子说对了。7、8
音频标签写在文本里的方括号指令，例如 [excited] 或 [whispers]。有的模型（如 ElevenLabs v3/v4）会当成表达方式来读。7
自回归（AR）一步一步生成，每一步都看前面已经生成的内容，像大语言模型写字。自然，但可能重复或漏掉。1
C2PA / Content Credentials给媒体文件附上签名来源元数据（「由工具 X 制作」）的开放标准，音频也算。9
CER 字错率字符错误率。算法和词错率一样，但按字数。中文词与词之间没有空格，所以用它量可懂度。7
切块把长稿切成句子或段落大小的块，分别合成，再接起来。1、8
语码转换一句话里混用两种语言，例如普通话里夹英语技术词。这是一项要单独测的能力。1、11
神经音频编解码器把音频压成离散整数符号再解回来的网络，例如 SoundStream、EnCodec、DAC。编解码语言模型的「分词器」。1
编解码语言模型一个 Transformer，根据文本加上一段声音提示，去预测音频编解码符号，像大语言模型预测下一个词。1
余弦相似度两个嵌入向量方向有多接近，分数在 −1 到 1 之间。用来量说话人相似度。7
跨语言克隆用你的声音说一段参考音频里没有的语言。1
dBFS相对于满刻度的分贝；0 dBFS 是数字文件能装下的最大响度。录音峰值通常要留在它下面。6
去混响去掉录音里房间回声的处理。用过头会产生瑕疵，克隆会把瑕疵一并学走。6
深度伪造（欧盟人工智能法）人工智能生成或篡改的图像、音频或视频，像真人、真实物体或真实事件，并且会让人误以为是真的（第 3 条第 60 款）。9
扩散模型一种生成模型，学会用很多步去噪，把噪声变成数据。1
漂移一次很长的生成里，或不同次生成之间，声音、语速或音高慢慢变了。1
说话人嵌入一段固定长度的向量，概括「谁在说话」，不依赖具体的词。1
F0 / 音高基频：每个时刻声音有多高或多低。声音转换会跟踪并把它搬过去。4
微调用你的录音继续训练一个已经预训练好的模型，让权重适应你的声音。1
流匹配一种生成式训练方法，学习一个速度场，用很少的步把噪声移到数据上。F5-TTS、E2 TTS、CosyVoice 的解码器用它。1
G2P字素到音素：把拼写转成发音符号。很多读错都出在这里。7
幻觉（语音合成）说出来的和文本对不上：漏词、重复、编造；含糊；长沉默。7
HuBERT / ContentVec自监督语音模型。它们的特征抓住「说了什么」，丢掉很多「谁说的」。声音转换里用作内容编码器。4
即时声音克隆（IVC）供应商对「用短样本做零样本克隆」的叫法。2
IPA 国际音标国际音标。用在 SSML 的 <phoneme> 标签和发音词典里。7
词典 / 发音词典一张表，把词映射到该怎么读（音素或改写别名），例如 “Kubernetes” → “koo-ber-NET-eez”。7
对口型数字人一张脸的视频，嘴型是根据音轨生成的。8
LoRA低秩适配：只微调一小套额外权重，而不是整个模型；更快、更轻。3
LUFS / LKFS相对于满刻度的响度单位，是 ITU-R BS.1770 和 EBU R128 里的感知响度。旁白会归一化到一个目标 LUFS。8
梅尔频谱按感知频率（梅尔刻度）画的声音时频图；语音合成里经典的中间表示。1
MOS 平均意见分听者给自然度打 1–5 分，平均就是 MOS。CMOS 比较两个系统；SMOS 给说话人相似度打分。7
非自回归（NAR）整段一起生成，而不是一步一步（例如流匹配）。更快，漏词更少。1
文本规范化在合成前把文本改写成能念的词：“3.5 GB” → “三点五吉字节”，“2026” → “二零二六”。7、8
响度规范化调整增益，让每个文件感知响度一样（目标 LUFS），峰值不超过真峰值上限。6、8
Personal Voice（Azure）微软的受限零样本声音克隆，必须录一段同意声明。2
音素能区分词的最小声音单位，例如英语 “cat” 里的 /k/。7
拼音普通话的罗马拼写，带声调数字或符号（例如 hang2）。好几个能说中文的模型接受它，用来改多音字。7
多音字一个汉字在不同上下文里有不止一种读法，例如行 xíng / háng。1、7
专业声音克隆（PVC）供应商对「用较长录音微调出来的声音」的叫法，通常要核验身份。2
韵律说话的旋律、节奏、重音和停顿。1
参考片段 / 提示音频零样本模型模仿的那一小段你的录音。1、6
房间底噪房间安静时的背景声。底噪一致，块与块接起来才听不出缝。6、8
RTF 实时因子处理时间除以音频时长。RTF 0.1 表示 100 秒音频用 10 秒计算。3
RVC基于检索的声音转换，一个流行的开源系统，用几分钟目标声音来训练。4
Seed-TTS-eval字节跳动公开的零样本语音合成测试集（英语、中文，另有一个「难」集），报告词错率 / 字错率和说话人相似度；很多论文用它。3、7
SNR 信噪比你的声音比背景噪声响多少，单位分贝。6
说话人验证判断两段录音是不是同一个人。它的模型既当相似度打分器，也当银行的「声纹」。7、9
SRT / WebVTT带时间戳的纯文本字幕格式，由词的时间生成。8
SSML语音合成标记语言：用 XML 标签标停顿（<break>）、发音（<phoneme>）、语速和音高（<prosody>）。各家、各模型支持不一样。7
音色让你认出一个人的那种声音「颜色」，不依赖音高和具体的词。1
真峰值（dBTP）重建后的模拟波形的最高电平，可以超过采样峰值；交付时通常限制在大约 −1 dBTP。8
TTS文本转语音。全站
视位 viseme对应一个语音的口型；用来驱动对口型。8
声码器把频谱变成波形的模型，例如 HiFi-GAN、BigVGAN、Vocos。1
声音转换（VC）语音到语音：保留词和时间，换掉声音。4
音频水印嵌在生成音频里、人耳听不见、检测器以后能找出来的信号，例如 SynthID、AudioSeal、PerTh。9
WER 词错率（替换 + 删除 + 插入）÷ 参考里的词数。把合成音频转写成文字，再和稿子比。7
零样本推理时用一小段样本克隆声音，不对这个声音做训练。1
