选择一套配置

三条现成的路径，一个按任意小时数算费用的计算器，以及一份短问卷，会推荐一套配置。每条推荐都当成你自己对比测试的短名单（第 11 页），不是最终判决。

免费本地，还是付费云？

付费云免费本地（开放权重）
今天的质量独立克隆音色榜的顶部（Eleven v4、Qwen-Audio 3.1、Sonic 3.6）。已核实基准数字和闭源一样好，但很少有开源模型在听者投票榜上。已核实
你的声音数据要上传；大多数供应商对它拿走很宽的许可（第 9 页）。从不离开你的机器。
费用英语大约每小时 0.80–6 美元；按字计费时普通话每小时更便宜。软件免费；你为显卡付钱（买或租）。
力气几分钟就有第一个结果。几小时到几天：Python、CUDA、下载模型；Windows 支持参差。
长期稳定供应商会改模型、改价格，也会关掉（Resemble 托管、LMNT、PlayHT）。钉死的模型不会变，但项目会停滞或被撤回（VibeVoice）。
商用付费方案上可以。只有 Apache/MIT 权重可以；很多强模型是非商用的。

三条路径

  1. ElevenLabs Starter（每月 6 美元）：每种语言用 1–2 分钟干净音频做即时声音克隆。第一天关掉「为所有人改进模型」。
  2. 在网页应用里用 Eleven v4 生成一课；把有问题的词加进发音词典。
  3. 想要便宜的对照，再在付费档上试 Gemini 3.8 Flash TTS 声音复刻（大约每音频小时 0.82 美元）。
  4. 能用了，就迁到 API 和第 8 页的流水线；如果即时还不够像，升到 Creator（22 美元）做专业声音克隆。

为什么：到好结果最快，普通话和英语都有，任何付费档都能商用，自动化的 API 最好。已核实（价格和功能）· 选择推断

  1. 硬件：8 GB 或更多的 NVIDIA，或按小时租（2026-10-17，RunPod 上 RTX 3090 大约每小时 0.50 美元）。你现在这块 Intel 核显只能慢慢走 CPU 路径。
  2. 从 GPT-SoVITS 开始（MIT）：官方 Windows 一键包；5 秒零样本，再用几分钟你的声音微调。
  3. 和 VoxCPM2 比（Apache-2.0，约 8 GB）看零样本相似度；如果要拼音覆盖和指令控制，比 Fun-CosyVoice 3（Apache-2.0）。
  4. 围绕赢家搭流水线；三个都有 Python API，VoxCPM2 和 CosyVoice 3 还有 HTTP 服务。

为什么：许可证商用干净，普通话强，声音留在本地。已核实（许可）· 选择推断

  1. 好好录（第 6 页）：主要语言 1–3 小时干净音频，另一种 30 分钟以上。
  2. ElevenLabs Creator（每月 22 美元）的专业声音克隆，用这套录音在 Eleven v4 上训练。
  3. 专门为普通话测亚军：MiniMax Speech 2.8 HD、阿里 Qwen-Audio、Cartesia Sonic 3.6；独立的普通话排名只有二手报道，所以信你自己的 A/B。
  4. 流水线带上词典、请求拼接、语音识别检查和强制对齐（第 8 页）；被标出的块要人听。

为什么：个人能用的服务里，独立听者评分最高，而且克隆是用多得多的你的声音训练的。已核实（竞技场、方案功能）· 选择推断
