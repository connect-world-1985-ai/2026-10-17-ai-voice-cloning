Tool explorer

Every cloud service, open model and voice-conversion tool from pages 2–4 in one sortable, filterable table. Click a column header to sort; use the chips to narrow down. All values were read on 2026-10-17.

How to read the numbers
  • Elo = Artificial Analysis Controlled Voice Arena (blind listener votes on cloned English voices). Only some models are on it. Gaps under ~20 are within the confidence interval. Verified
  • SIM EN / ZH = Seed-TTS-eval speaker similarity ×100, self-reported by model authors (two real recordings of the same person score about 73 / 75). Comparable only within this column. Verified (as published)
  • $/h = list price for one hour of finished narration (EN ≈ 50–60k characters, ZH ≈ 15k characters). Open models show 0: you pay with hardware or GPU rental instead; see the cost calculator.
  • Commercial: yes = code and weights (or paid plan) allow it; cond. = allowed under conditions in the notes; no = non-commercial; unclear = sources conflict or are silent. Not legal advice.
