Open-source voice-cloning models

Open models now match or beat closed ones on the standard benchmark, and they keep your voice on your own machine. The catch is not quality. It is licences (many strong models forbid commercial use), hardware (most want an NVIDIA GPU), and Windows support.

Bottom line (state on 2026-10-17)
  • Commercially clean with English, Mandarin and cross-lingual cloning (Apache-2.0 or MIT for code and weights): VoxCPM2, Fun-CosyVoice 3 (0.5B), Qwen3-TTS, GPT-SoVITS, Chatterbox Multilingual. Verified (licence texts and Hugging Face tags; main agent re-checked VoxCPM, CosyVoice 3, Qwen3-TTS)
  • Non-commercial weights, fine for experiments but not for a paid course: F5-TTS, XTTS-v2 (its licence explicitly covers outputs), Fish Audio S2-Pro / Drama 3, Spark-TTS, MaskGCT, Llasa. Verified (main agent re-read F5, XTTS, Fish licence texts)
  • Easiest start on Windows: GPT-SoVITS, the only one with an official one-click Windows package, and it can fine-tune on about a minute of your voice. Verified (README)
  • Your current PC (Intel UHD graphics, no NVIDIA GPU) can run only a few of these, slowly. Plan on a 8–24 GB NVIDIA card or an hourly GPU rental; see hardware below. Inference

The recommended shortlist

VoxCPM2 (OpenBMB)

Apache-2.0. 2B, 30 languages, 48 kHz, ~8 GB VRAM. Highest self-reported similarity of the commercially usable models (SIM 75.3 EN / 79.5 ZH). Cross-lingual without language tags; LoRA fine-tuning; OpenAI-compatible server via vLLM-Omni. Demo page

Fun-CosyVoice 3 0.5B (Alibaba)

Apache-2.0. Explicit cross-lingual mode, instructions for speed and emotion, pinyin and phoneme fixes for technical terms, 18+ Chinese dialects, FastAPI/gRPC servers. Linux-first: on Windows expect WSL2. Demo page

Qwen3-TTS 1.7B (Alibaba Qwen)

Apache-2.0. Clones from 3 s plus transcript; very low self-reported error rates; about 5–6 GB VRAM (secondary). Repository quiet since 2026-03-17. Use 1.7B rather than 0.6B for long narration (secondary report).

GPT-SoVITS

MIT. Official Windows one-click package, built-in slicing, ASR and labelling tools, fine-tune on ~1 minute or more of your recordings. Strong Chinese heritage. The path if zero-shot is not "you" enough.

Also worth a look: IndexTTS-2.5 (bilibili) has the best self-reported cross-lingual similarity and fine control of duration and emotion; its licence is royalty-free below 100 million monthly users or RMB 1 billion revenue, but its README says to contact bilibili for commercial use, so ask before launching a paid product. Chatterbox (MIT) is the simplest install, but every output carries an inaudible watermark and its accent leaks when the reference language differs from the target. Verified

Reading the benchmarks
  • Error rates no longer separate the top models: almost all are at or below human level on read sentences. Similarity and your own listening matter more. Inference
  • Cross-lingual similarity drops by about 10 points for every model (zh→en SIM 56–68 versus 71–80 within one language). Expect your "other language" voice to sound less like you. No English→Chinese numbers were found. Verified (CV3 table) · interpretation Inference
  • Arenas with listener votes are English-only and mostly use stock voices. On the independent cloned-voice board, the best open models listed rank far below the top cloud services (Chatterbox 930, XTTS-v2 830 versus Eleven v4 1159). Most of the shortlist above is not on that board at all. Verified

Licence traps

  • Code licence ≠ weights licence. F5-TTS: "Our code is released under MIT License. The pre-trained models are licensed under the CC-BY-NC license due to the training data Emilia". The same pattern applies to Spark-TTS, MaskGCT and others. Verified (main agent re-read the README)
  • XTTS-v2 covers outputs explicitly: "This license allows only non-commercial use of a machine learning model and its outputs." Coqui has closed, so there is no one to buy a commercial licence from. Verified (licence text)
  • Fish Audio: the code licence is not the weights licence. The code licence allows commercial use "only while Your Annual Revenue is less than USD 500,000", but the S2-Pro weights licence says "No commercial rights are granted under this Agreement." Verified (both texts)
  • IndexTTS: royalty-free use, a separate licence above 100 million monthly active users or RMB 1 billion annual revenue, and a ban on using it or its outputs "to improve any AI model, except … non-commercial AI models". The README adds "For commercial usage and cooperation, please contact". For an individual's course the text appears to allow it; confirm by email. Verified (licence text) · reading Inference
  • OmniVoice: unclear. A research helper reported a non-commercial weights statement in the README; the main agent found no such statement in the current README on 2026-10-17; the repository is Apache-2.0, the Hugging Face card has no licence tag, and it was trained partly on Emilia (non-commercial). Treat it as non-commercial until clarified. Unverified
  • Higgs TTS 3: research and non-commercial, plus a Creator Use Grant allowing monetised videos and podcasts on channels you own if you credit "Boson AI's Higgs Audio". A course on a platform you do not own is unclear. Verified (helper read the licence)
  • Whether non-commercial terms reach the audio you generate is legally debated. The conservative reading: if commercial use is possible, use only "Yes" models. Inference

Withdrawn, stale and limited

  • VibeVoice TTS (Microsoft): "we have removed the VibeVoice-TTS code from this repository" (2025-09-05), after misuse; README: "intended for research and development purposes only". Only community forks remain. Avoid for a long-term pipeline. Verified (main agent re-read the README)
  • Coqui TTS: the original repository has been unmaintained since 2024-08; the idiap fork (coqui-tts, Windows wheels) is maintained. Verified
  • MegaTTS3: Apache-2.0, but the voice encoder is not released; you must upload a sample to a Google Drive folder to get usable voice latents. That defeats the point of a private local clone. Verified (README)
  • No Chinese, or no cloning: Kyutai Pocket TTS (CPU-first, English and European languages), Sesame CSM, Dia2 and Orpheus (English-centric), Kokoro (excellent but preset voices only). Verified
  • Stale (no push for 12+ months): Spark-TTS, Zonos, OpenVoice V2, StyleTTS 2, Sesame CSM. Verified (GitHub API)
